# Supermarket Stock Management Database

This project is a MySQL database schema for a supermarket stock management
system. It supports inventory tracking across stores and warehouses, online
orders, and stock movement logging.

The database was designed to practise relational database design concepts,
including entity relationships, normalization, and data integrity constraints.

## Features
- Product categorization and supplier tracking
- Store and warehouse inventory management
- Online order processing
- Stock movement logging for inventory updates

## Technologies
- MySQL
- phpMyAdmin (XAMPP)

## Files
- `schema.sql` — complete database schema

## How to Run
1. Start MySQL using XAMPP
2. Open phpMyAdmin
3. Run `schema.sql` in the SQL tab

## Notes
This project focuses on database design and does not include an application
layer.
